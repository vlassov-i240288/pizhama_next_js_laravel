# Реклама pizhama.kz: Google Ads и Яндекс Директ

Три поисковые кампании: **Сайты**, **CRM** и **Чат-боты**. В них 19 групп объявлений и 130 ключевых фраз.
Каждая группа ведёт на свою посадочную страницу сайта. Все ссылки проверены и открываются.

| Файл | Для чего |
|---|---|
| `campaigns.mjs` | Тексты, ключи, бюджеты. Правьте только этот файл |
| `build.mjs` | Проверяет лимиты символов и собирает файлы ниже: `node build.mjs` |
| `google-ads-editor.csv` | Импорт в Google Ads Editor: кампании, группы, ключи, минус-слова, объявления |
| `yandex-direct.md` | Всё для Директа в удобном виде: тексты, ключи, быстрые ссылки, уточнения |
| `yandex-ads.csv`, `yandex-keywords.csv` | Те же данные таблицей, чтобы вставить в Excel-шаблон Директ Коммандера |

## Старт с Актобе (рекомендуемый первый шаг)

Файлы `google-ads-editor-aktobe.csv` и `yandex-direct-aktobe.md` описывают одну кампанию **PIZHAMA | Актобе | Поиск**.
В ней 5 групп: сайты под ключ, лендинги, интернет-магазины, чат-боты и CRM. Всего 43 фразы.

Данные Планировщика ключевых слов Google, Актобе (город), ноябрь 2025 – октябрь 2026:
- коммерческие запросы («создание / разработка / заказать / сделать сайт») дают по 10–100 поисков в месяц, вместе 40–400;
- ставка за верх страницы 0,3–1,5 $, а по Казахстану 4–6 $;
- «сайт», «чат бот», «crm» без уточнений в основном ищут не заказ услуги, поэтому в кампании они только с уточнениями;
- в минус-словах добавлены ChatGPT, «вход» и «личный кабинет».

Настройки:
- **Регион:** только «Актобе». В Google выберите вариант «Присутствие», чтобы не показываться тем, кто просто интересуется городом. Слово «актобе» в ключах не нужно.
- **Бюджет:** 2 000 ₸ в день. При малом спросе больше он не потратит.
- **Стратегия:** «Максимум кликов» с ограничением цены клика около 500 ₸.
- **Через 2–3 недели** посмотрите, сколько было заявок. Если мало, включите кампании по всему Казахстану (основные файлы ниже). Удалённо там спрос в 10 раз больше.

## 0. До запуска рекламы (обязательно)

1. ~~Форма заявки~~ — готово: заявки приходят на info@pizhama.kz (DKIM, кнопки WhatsApp/Telegram) и сохраняются в `frontend/data/leads.jsonl` на сервере.
2. **Установите Яндекс Метрику.** Без неё Директ не видит заявки и не умеет оптимизировать ставки.
   - Создайте счётчик на metrika.yandex.ru для сайта `pizhama.kz`. Включите вебвизор.
   - На сервере создайте `frontend/.env.production` со строкой `NEXT_PUBLIC_YANDEX_METRIKA_ID=<номер счётчика>`.
     Затем пересоберите сайт: `npm run build` и `sudo systemctl restart pizhama`.
   - В Метрике добавьте цели типа «JavaScript-событие» с идентификаторами:
     `lead_form` (заявка с формы), `whatsapp_click`, `telegram_click`, `phone_click`.
3. **Проверьте цены в калькуляторе** (`frontend/components/sections/project-calculator.tsx`).
   Из рекламы люди часто идут считать стоимость. Цифры должны совпадать с вашим реальным прайсом.

Каждая заявка теперь приходит с источником, например: `Источник: utm_source=yandex&utm_campaign=...&utm_term=crm для салона красоты | /services/crm-erp/beauty-salon`.
Так видно, какое объявление и какой запрос принесли клиента.

## 1. Google Ads

1. Создайте аккаунт на ads.google.com в режиме эксперта, без «умной кампании». Валюта: тенге.
2. **Конверсии.** В Google Analytics (`G-WT3X2H11V0`) откройте «Администратор» → «События».
   Отметьте как ключевые события `lead_form`, `whatsapp_click`, `telegram_click`, `phone_click`.
   События появятся там после первых срабатываний на сайте.
   Затем свяжите GA4 с Google Ads и импортируйте эти конверсии: «Цели» → «Конверсии» → «Импорт» → Google Analytics 4.
3. Установите **Google Ads Editor**, войдите в аккаунт и выберите «Аккаунт» → «Импорт» → «Из файла».
   Укажите `google-ads-editor.csv`. Проверьте изменения и нажмите «Опубликовать».
4. В каждой кампании проверьте настройки:
   - **Местоположения:** Казахстан. Для Актобе можно поставить корректировку ставки +20%.
     Вариант «Присутствие: люди, которые находятся в регионе» вместо «интересуются».
   - **Сети:** только поиск. Галочку «Контекстно-медийная сеть» снимите.
   - **Стратегия:** первые 2–3 недели «Максимум кликов» с ограничением цены клика.
     Когда наберётся 15–30 конверсий за месяц, переключите на «Максимум конверсий».
   - **Расписание:** можно оставить круглосуточно. Позже отключите часы без заявок.
5. Добавьте расширения: номер телефона `+77019204449`, быстрые ссылки и уточнения.
   Можно взять те же, что для Директа, из `yandex-direct.md`.

## 2. Яндекс Директ

1. На direct.yandex.ru создайте **Единую перфоманс-кампанию**, тип «Поиск», для каждой из трёх кампаний.
   Или загрузите тексты через Директ Коммандер из CSV.
2. Для каждой группы из `yandex-direct.md`:
   - вставьте заголовки, текст, ссылку (UTM-метки в ней уже есть) и отображаемую ссылку;
   - вставьте ключевые фразы;
   - добавьте быстрые ссылки и уточнения кампании;
   - добавьте изображение: подойдут скриншоты из `frontend/public/cases/` или логотип.
3. Минус-слова из начала `yandex-direct.md` добавьте на уровне кампании.
4. **Регион показа:** Казахстан. Корректировка для Актобе: +20%.
5. **Стратегия:** сначала «Максимум кликов» с недельным бюджетом.
   После 10+ конверсий в неделю переключите на «Максимум конверсий» с целью `lead_form` и мессенджерами.
6. **Счётчик Метрики** укажите в настройках кампании. Включите автоматическую разметку `yclid`.

## 3. Бюджет и первые две недели

- В `campaigns.mjs` заложено 3 000 ₸ в день на сайты, 2 500 ₸ на CRM и 2 000 ₸ на чат-боты.
  Это **стартовая точка для теста, а не прогноз**. Реальная цена клика станет понятна через 3–5 дней.
- Если бюджет маленький, запустите только группы «Разработка сайтов» и «Разработка CRM», остальные поставьте на паузу.
- **Каждый день первые 2 недели** смотрите отчёт «Поисковые запросы» в Google и «Поисковые запросы» в Директе.
  Нецелевые фразы добавляйте в минус-слова: «вакансии», «курсы», названия конструкторов и так далее. Это главная экономия бюджета.
- Через 2 недели отключите группы с кликами, но без заявок, и поднимите бюджет на те, что приносят заявки.

## Как менять объявления

Откройте `campaigns.mjs`, поправьте тексты или ключи и выполните `node build.mjs`.
Скрипт сообщит, если текст длиннее лимита. Лимиты Google: заголовок 30, описание 90.
Лимиты Директа: заголовок 56 и 30, текст 81, отображаемая ссылка 20.
